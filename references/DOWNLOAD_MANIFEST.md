## Fallback if a missing paper cannot be located

Each missing reference has a fallback so the methodology paper can
be submitted without it if necessary. The fallback is not
equivalent to citing the original, but it lets us keep the
argument.

- Ref 02 (Rothbaum 1995) — cite indirectly through Ref 04 (Powers
  & Emmelkamp 2008 meta-analysis), which reviews it and lists the
  full effect sizes. We already have Ref 04.

- Ref 05 (Botella 2017) — replace with Ref 34 (Diemer 2015) or
  add an alternative open-access systematic review. Both cover the
  same territory. We already have Diemer.

- Ref 19 (Boucsein book) — keep the citation without a PDF.
  Reviewers accept book citations without attached PDF. The book is
  the authoritative reference for EDA methodology and does not have
  a good open substitute.

- Ref 20 (Dawson chapter) — same as Ref 19; keep the citation, no
  PDF attached, no reviewer will flag this.

- Ref 24 (Lippman 1994) — the Malik 20 % rule which this paper
  formalises is fully described in Ref 15 (Task Force 1996), which
  we already have. Cite Task Force 1996 for the rule and mention
  Lippman 1994 as the historical origin in a footnote.
